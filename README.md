## Data Reduction and Observation Details

Data reduction for this project was conducted using version 6.6.3.22 of the Common Astronomy Software Applications (CASA; McMullin et al. 2007) software package. The observations focused on the Andromeda Galaxy (M31) using the Very Large Array (VLA) telescope and included three bands: L, S, and C bands.

- **L Band**: Unfortunately, due to solar activity, the L band data was compromised and did not contain any usable polarization signal.
- **S Band**: The S band data was successfully reduced but was heavily impacted by radio frequency interference (RFI), making the reduction process particularly challenging.
- **C Band**: Details of the C band processing will be included in future updates.

### Observation Goals
The primary goal of this observation is to study segments of M31's spiral arms with angular sizes of approximately \(6'\), analyzed at high resolution to explore their structure and magnetic field properties.
